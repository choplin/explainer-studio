understanding-html-docs デザインシステム ショーケース

このページは base スキル（understanding-html-docs）が提供する デザインシステムと進行的強化（PE）キットの全コンポーネントを一望するための 目視確認用ページです。右上のテーマボタンで 自動 / ライト / ダーク を切り替え、各コンポーネントが両テーマで成立しているかを確認できます。

確認の観点 — 特に ダークの <mark> ハイライト帯（白文字とのコントラスト）と、 ライトの --cat-soft 背景塗り（白地での視認性）を両テーマで見比べてください。 どちらも直近で調整したトークンです。

1. タイポグラフィと基本要素

段落は自動で body / p のスタイルが当たります。 リンクはグローバルアクセント固定で このように 表示され、 インラインの code は地色と別のコードトーンになります。 重要語は この蛍光ペン下線帯（<mark>） で強調でき、 ダークテーマでは白文字が帯に乗っても読める濃さになっているのが要確認点です。

1.1 見出しと引用

引用（blockquote）は左罫線とミュート文字で本文から一段引きます。 出典や補足の直接引用に使います。

順序なしリストと順序付きリスト:

  • foundation は要素セレクタで自動適用される
  • 名前付きコンポーネントはクラスで opt-in する

3. Callout（セマンティック・メッセージ箱）

基底クラス .callout は note（情報）。バリアントで意味・色・アイコンが変わります。

Note — 一般的な補足情報。基底の青。
Tip — 役立つヒント。緑。
Warn — 注意喚起。橙。
Danger — 危険・破壊的操作。赤。
Key — 重要な要点。紫。

4.1 プルクオート・キッカー・リード

プルクオートは一行を強く見せ、引用符をカテゴリカル色で描く。

リード（lede）は導入段落を少し大きくミュートで見せ、本文への入口を作る。

aside はアイコンもセマンティック色も持たない静かな補足。脚注的な文脈を本文からわずかに離して置く。

9. Tier 2 opt-in コンポーネント

base 基盤（オフライン）に対し、重量レンダラは opt-in の Tier 2 コンポーネントとして assets/components/<name>/ に分離し、使う文書だけがコピーします。エンジンは既定で CDN から読み込みます（このページのデモも同様）。

閲覧方法 — このデモは ES モジュール（diagram）と CDN を使うため、file:// で直接開くとブラウザが module を読み込めず diagram が描画されません。ローカルサーバ経由で開いてください（例: python3 -m http.server → http://localhost:8000/showcase.html）。

9.1 highlight — シンタックスハイライト（highlight.js）

<pre><code class="language-*"> を highlight.js で着色。配色は highlight.css の light-dark() テーマでテーマ追従します。 

// two-layer color model — semantic vs categorical
type Layer = "semantic" | "categorical";
interface Token { name: string; light: string; dark: string; }

function resolve(tokens: Token[], dark = false): Map<string, string> {
  return new Map(tokens.map((t) => [t.name, dark ? t.dark : t.light]));
}

const marks: Token[] = [
  { name: "--mark", light: "#ffe08a", dark: "#8a6a12" },
];
console.log(resolve(marks, /* dark */ true));

9.2 diff — git diff の描画（diff2html）

pre.diff-source（有効な unified diff）＋直後の div.diff-render のペアを描画。下のボタンで表示形式を切り替え。 

diff --git a/assets/base.css b/assets/base.css
--- a/assets/base.css
+++ b/assets/base.css
@@ -38,3 +38,3 @@
   --key:  light-dark(#7c3aed, #c4b5fd); --key-soft:  light-dark(#f5f3ff, #201a2e);
-  --mark: light-dark(#ffe08a, #b8912f);   /* highlighter-pen band color */
+  --mark: light-dark(#ffe08a, #8a6a12);   /* dark: deep so white text stays legible */
   --cat: var(--accent); --cat-soft: var(--accent-soft);
